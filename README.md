# grade-report

从一张 CSV 成绩单自动生成统计报告：各课程分析、分数段分布、学生加权排名与 GPA。

**零第三方依赖**——只用 Python 标准库，`python grade_report.py` 直接跑，不用 `pip install` 任何东西。

![Python](https://img.shields.io/badge/python-3.8%2B-blue)
![Dependencies](https://img.shields.io/badge/dependencies-0-brightgreen)
![Tests](https://github.com/Wang-Xinyu-2007/grade-report/actions/workflows/tests.yml/badge.svg)

---

## 为什么写这个

手动在 Excel 里拉公式算加权平均分、排名、及格率，每学期都要重来一遍，而且是重复劳动。
这个工具把它变成一条命令。

---

## 功能

- **各课程统计**：选课人数、平均分、中位数、最高/最低分、标准差、及格率
- **分数段分布**：纯文本横向条形图，一眼看出这门课是正态还是两极分化
- **学生排名**：按学分加权平均分排序，同分并列同名次，附带 4.0 制 GPA 和挂科门数
- **单人查询**：`--student 学号` 看某个学生的完整成绩单
- **导出 CSV**：UTF-8-BOM 输出，Excel 双击不乱码
- **读得进各种脏数据**：UTF-8 / UTF-8-BOM / GBK 编码自动识别，逗号 / 分号 / 制表符分隔符自动识别，中英文列名都认

## 快速开始

```bash
# 1. 拿到代码
git clone https://github.com/Wang-xinyu-2007/grade-report.git
cd grade-report

# 2. 直接跑（不需要装任何包）
python grade_report.py data/sample_grades.csv
```

仓库自带一份 12 人 × 5 门课的示例数据，clone 下来立刻能看到效果。

---

## 输入格式

CSV 需要这 5 列，**顺序随便，中英文列名都认**：

| 列名 | 也可以写成 | 说明 |
| --- | --- | --- |
| 学号 | student_id / id | 学生的唯一标识 |
| 姓名 | name | |
| 课程 | course / 科目 | |
| 学分 | credit | 必须为正数 |
| 成绩 | score / 分数 | 0~100 |

示例（`data/sample_grades.csv`）：

```csv
学号,姓名,课程,学分,成绩
2024110301,林知远,数学分析,5,92
2024110301,林知远,高等代数,4,88
2024110302,陈屿,数学分析,5,78
```

少于这 5 列会明确报错告诉你缺哪个，不会静默算错。

---

## 用法

```bash
# 完整报告
python grade_report.py data/sample_grades.csv

# 只看前 5 名
python grade_report.py data/sample_grades.csv --top 5

# 查某个学生的成绩单
python grade_report.py data/sample_grades.csv --student 2024110304

# 导出汇总结果到 CSV
python grade_report.py data/sample_grades.csv --export result.csv

# 看所有参数
python grade_report.py --help
```

## GPA 换算规则

采用常见的分段算法（非单一学校标准，想改直接改 `score_to_gpa()` 一个函数）：

| 百分制 | 绩点 | | 百分制 | 绩点 |
| --- | --- | --- | --- | --- |
| 90–100 | 4.0 | | 72–74 | 2.3 |
| 85–89 | 3.7 | | 68–71 | 2.0 |
| 82–84 | 3.3 | | 64–67 | 1.5 |
| 78–81 | 3.0 | | 60–63 | 1.0 |
| 75–77 | 2.7 | | < 60 | 0.0 |

GPA 和加权平均分一样按学分加权：`Σ(绩点 × 学分) / Σ学分`。

## 已知限制

- 假设一个学生对同一门课只有一条记录（重修成绩不做覆盖处理）
- 排名依据加权平均分，不是教务系统常见的学分绩点排名
- 输出走终端，Windows 老终端若出现乱码先执行 `chcp 65001`
